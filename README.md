# 江苏13市共青团「青年夜校」推文数据平台

## 项目说明

本项目是对 **江苏13个设区市** 团委官方公众号（"青春+城市名"）发布的青年夜校相关推文进行系统检索后，构建的可视化数据展示平台。

## 数据范围

| 项目 | 内容 |
|---|---|
| 检索时间范围 | 2024年1月1日 — 2026年8月21日 |
| 覆盖城市 | 南京、苏州、无锡、常州、镇江、南通、扬州、盐城、淮安、连云港、徐州、泰州、宿迁 |
| 官方公众号 | 均为"青春+城市名"（如"青春南京""青春盐城"） |
| 收录推文 | 52 篇核心推文 |
| 子账号 | 各县区团委公众号（如"大丰共青团""青春宿豫""连云新青年"等） |

## 关键发现

### 宣传视频情况
- **绝大多数推文为纯图文形式**，仅有 1 篇（共享南京分公司团委）在推文中嵌入了短视频
- 宣传视频主要出现在**上级媒体转载**（新华报业网、中国共青团杂志）和**短视频平台**（视频号/抖音）
- 盐城大丰共青团推文全部为图文，无独立宣传视频

### 运营模型（13市共性）
- ✅ 官方唯一性："青春+城市名"为唯一官方发布渠道
- ✅ 公益为主：90%以上课程免费，仅收取材料/成本费
- ✅ 实名制+限额：18-45岁青年，先到先得
- ✅ 青年之家为核心阵地
- ✅ AI课程成标配（2025下半年起全面接入）

### 盐城大丰专题
- 主阵地：创想家人才社区服务中心 + 盐城经开区1992人才会客厅
- 合作方：团区委 + 区城建集团 + 区人社局 + 新团职校 + 大丰瓷刻非遗工坊
- 2026年起升级为"技能夜校"，新增消防设施操作、互联网直播、养老护理等就业导向课程
- 供稿人：宗文清（高频）、韦璇、冯嘉瑞等

## 本地运行

由于使用了 `fetch` 加载 JSON，需通过 HTTP 服务器访问：

```bash
# Python 3
python -m http.server 8000

# 然后浏览器打开
# http://localhost:8000
```

## 数据字段说明

每条推文记录包含以下字段：

| 字段 | 说明 |
|---|---|
| title | 推文标题 |
| date | 发布时间（年月） |
| source | 发布账号 |
| url | 推文链接 |
| content_type | 内容形式（图文/图文+视频） |
| has_video | 是否含宣传视频 |
| video_count | 视频数量 |
| venue | 上课场地 |
| courses | 课程列表 |
| organizer | 主办单位 |
| target_group | 覆盖人群 |
| fee | 费用 |
| participants | 参与情况 |
| key_feature | 核心亮点 |

## 数据来源声明

所有数据来源于各市团委官方微信公众号公开推文，检索时间为2026年8月。部分数据经上级媒体转载（新华报业网、中国共青团杂志、无锡日报、宿迁发布等）补充验证。
